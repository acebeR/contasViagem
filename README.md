Nome do Projeto: Controle de Despesas

# Descrição Geral:
O site é uma aplicação web que permite gerenciar despesas de forma simples e organizada. Ele foi desenvolvido para ajudar grupos de pessoas a controlar quem pagou o quê, calcular quanto cada participante deve para os demais, e gerar relatórios claros de forma automatizada.
# Principais Funcionalidades:
Cadastro de participantes: Permite inserir o número de pessoas que participam do grupo e cadastrar seus nomes.
Registro de despesas: Cada despesa pode ser adicionada com descrição, valor, quem pagou e quais participantes participaram.
Edição e exclusão de despesas: Possibilidade de corrigir informações ou remover despesas registradas.
Cálculo automático de dívidas: A aplicação calcula quanto cada participante deve ou tem a receber, considerando todas as despesas registradas.
Resumo visual: Exibe uma tabela resumida mostrando os valores devidos entre os participantes.
Importação e exportação de dados: Permite baixar todas as informações em um arquivo JSON ou carregar dados previamente salvos.
Interface intuitiva: Layout simples com botões claros e formulários de fácil preenchimento.
# Público-alvo:
Grupos de amigos ou familiares que compartilham despesas de viagens, festas ou eventos.
Pequenos times de trabalho que precisam dividir custos de projetos ou compras coletivas.
# Diferenciais:
Totalmente front-end com armazenamento local (JSON), não depende de banco de dados complexo.
Atualização dinâmica da tabela de despesas e dívidas sem necessidade de recarregar a página.
Funcionalidade de edição intuitiva que permite corrigir informações sem perder dados anteriores.
