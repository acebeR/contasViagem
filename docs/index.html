Sobre este projeto

Nome do Projeto: Controle de Despesas

Descrição Geral: O site é uma aplicação web que permite gerenciar despesas de forma simples e organizada. Ele foi desenvolvido para ajudar grupos de pessoas a controlar quem pagou o quê, calcular quanto cada participante deve para os demais e gerar relatórios claros de forma automatizada.

Principais Funcionalidades Público-alvo
  • Cadastro de participantes: Inserir número de pessoas e cadastrar nomes.
  • Registro de despesas: Adicionar descrição, valor, pagador e participantes.
  • Edição e exclusão de despesas: Corrigir ou remover despesas.
  • Cálculo automático de dívidas: Calcula quanto cada participante deve ou recebe.
  • Resumo visual: Mostra tabela resumida de valores devidos.
  • Importação/exportação de dados: Baixar ou carregar informações em JSON.
  • Interface intuitiva: Layout simples e formulários claros.
  • Grupos de amigos ou familiares em viagens, festas ou eventos.
  • Pequenos times de trabalho que dividem custos de projetos ou compras coletivas.
Diferenciais
  • Front-end completo com armazenamento local (JSON), sem banco de dados complexo.
  • Atualização dinâmica da tabela de despesas e dívidas sem recarregar a página.
  • Edição intuitiva que mantém dados anteriores ao corrigir informações.
